# Karan Bansal

I build open-source tools for AI coding agents and write about what I learn from building and using AI systems.

## Start here

- **Understand AI:** [AI Dojo](https://aidojo.si/) has free explainers and exercises on how AI systems work, where they help, and where they fall short.
- **Use Claude Code tooling:** [Claude Code Hooks](https://github.com/karanb192/claude-code-hooks) provides installable hooks for secret protection, Git safety, cost visibility, and observability. These are guardrails, not a sandbox.
- **Understand cache costs:** [Cache Tax](https://github.com/karanb192/cache-tax) estimates the rewrite cost before a cold send and can keep selected sessions warm during breaks. Warming costs tokens; estimates use API-equivalent prices, not extra subscription charges.
- **Compare mods:** [Claude Code Mods catalog](https://github.com/karanb192/awesome-claude-code-mods) is a directory with scanner results showing what each mod can access. A declared footprint is not a security audit.
- **Read or watch:** [Writing](https://karanbansal.in/blog/) and [talks](https://karanbansal.in/talks/) on AI systems, coding agents, and security engineering.
